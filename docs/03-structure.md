# 主要目录结构

```
noheir/
├── public/                # 静态资源
├── src/
│   ├── components/        # 业务与通用组件
│   ├── contexts/          # 全局上下文
│   ├── domain/            # 纯业务规则与计算
│   ├── hooks/             # 自定义 Hooks
│   ├── lib/               # 工具与核心逻辑
│   ├── pages/             # 页面级组件
│   ├── services/          # 数据服务
│   ├── types/             # 类型定义
│   ├── viewmodels/         # 视图模型与派生逻辑
│   └── main.tsx           # 应用入口
├── tests/                 # 单元测试
├── docs/                  # 项目文档
├── package.json
└── vite.config.ts
```
