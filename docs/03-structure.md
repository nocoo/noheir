# 主要目录结构

```
noheir/
├── public/                # 静态资源
├── src/
│   ├── components/        # 业务与通用组件
│   ├── hooks/             # 自定义 Hooks
│   ├── lib/               # 工具与核心逻辑
│   ├── pages/             # 页面级组件
│   ├── services/          # 数据服务
│   ├── types/             # 类型定义
│   └── main.tsx           # 应用入口
├── scripts/               # 开发辅助脚本
├── docs/                  # 项目文档
├── package.json
└── vite.config.ts
```
