# 开发规范

## 技术栈

- React 18 + TypeScript
- Vite + Bun
- Tailwind CSS + shadcn-ui
- Supabase（PostgreSQL + Auth + Storage）

## 运行命令

```bash
bun run dev
bun run build
bun run lint
```

## 提交规范

- 采用原子化提交
- 单一逻辑变更一个 commit
- 需要保持可回滚与可构建

## 文档同步

- 修改功能、流程或接口时同步更新文档
- 文档信息必须准确、可执行
