# 文档规范

## 文档入口

所有文档从根目录 `README.md` 进入，按编号循序渐进阅读。

## 命名规则

- 统一存放在 `docs/`
- 采用编号前缀：`01-xxx.md`、`02-xxx.md`
- 全部使用英文小写与连字符

## 更新要求

- 修改功能或运行方式时，必须同步更新对应文档
- README 仅保留概览与导航，细节下沉到 `docs/`
- 任何新增目录与流程需补充到文档树

## 贡献规范

- 采用原子化提交：单一逻辑变更一个 commit
- UT 覆盖率目标 90%，新增逻辑必须补测
