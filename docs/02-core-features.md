# 主要功能

## 收支分析

- 收入、支出、转账三类交易统一建模
- 多维度分类（主类/子类/三级）支持
- 月度/年度趋势、同比对比与热力图

## 储蓄率与财务健康度

- 储蓄率趋势与目标管理
- 财务健康评分与结构分析
- 收入/支出结构对比

## 资产与资金单元管理

- 资产产品库与资金单元编组
- 资金流动性分级与解锁提示
- 资产配置结构可视化

## 数据导入与质量

- CSV/JSON 导入交易数据
- 数据质量检查与异常提示

## 账户与身份

- Supabase 身份认证与权限隔离
- Google OAuth 登录
